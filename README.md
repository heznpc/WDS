# WDS — What Did you Say?

**AI에게 보내기 전, 내 요청의 군더더기를 정리하고 가져온 의견의 출처와 용도를 구분하는 입력 도구.**

WDS는 평소 쓰는 입력창에서 사용자의 의도가 명확히 전달되도록 돕습니다. 필요한 구간만 사용자가 선택해 편집하고, 다른 세션에서 가져온 내용을 내 요청과 구분하는 것이 제품의 중심입니다. 시각 효과는 사용자가 적용한 편집을 보여줍니다.

현재 구현은 **macOS 소스 빌드 알파**입니다. WDS를 범용 제품으로 확장하기 위해 공통 코어와 플랫폼별 연결부를 나누는 방향을 잡았으며, 브라우저 확장은 아직 구현되지 않았습니다.

## 두 가지 독립 기능

| 기능 | 하는 일 |
| --- | --- |
| **입력 정리** | 요청과 무관한 군더더기와 제한적인 표기 오류를 후보로 제안합니다. 사용자가 승인한 구간만 삭제·교정합니다. |
| **출처 구분** | 다른 세션의 의견에 출처 경계와 검토 지침을 붙입니다. 사용자가 실제 요청으로 채택한 AI 개선본과, 비교·토론할 외부 의견을 구분하는 방향으로 확장합니다. |

두 기능은 각각 켜고 끌 수 있어야 합니다. 독립 스위치와 명시적 외부 의견 가져오기는 작업 브랜치에 구현돼 있고, **사용 목적 구분과 복사 경로에 따른 자동 표시는 아직 설계 단계**입니다.

작업 브랜치의 기준 커밋은 [`a49e662`](https://github.com/heznpc/WDS/commit/a49e6626115055817ec577ac09f4047ba6ef6131)입니다. [해당 CI](https://github.com/heznpc/WDS/actions/runs/34719910509)는 테스트와 번들 빌드를 통과했습니다. 앱 실행을 확인했지만, 두 스위치의 메뉴 클릭과 실제 입력 편집 조합은 미검증입니다. CI 통과를 모든 대상 앱의 호환성 확인으로 간주하지 않습니다.

교정 규칙과 출처 삽입 등 작업 브랜치의 상세 구현 설명은 [기준 커밋의 개발 가이드](https://github.com/heznpc/WDS/blob/a49e6626115055817ec577ac09f4047ba6ef6131/README.md)에 보존돼 있습니다.

현재의 웹앱 지원은 **Mac 브라우저가 접근성 API로 노출하는 입력창**을 대상으로 합니다. 다른 운영체제의 웹앱까지 지원한다는 뜻은 아닙니다.

## Mac에서 시작하기

Swift/Xcode 명령줄 도구를 사용할 수 있는 Mac에서 저장소 루트 기준으로 실행합니다.

```bash
./script/build_and_run.sh
```

메뉴바의 `현재 앱에서 WDS 시작…`에서 대상 앱의 접근 권한과 감시를 허용합니다. 입력창 옆에 후보가 나타나면 `유지` 또는 `날리기`를 선택합니다. WDS는 Enter나 전송 버튼을 누르지 않습니다.

현재 Mac 앱의 분석은 로컬 규칙으로 실행되며 모델·API 키가 필요하지 않습니다. 기능별 메뉴, 권한, 터미널의 미완성 범위, 패키징과 테스트 명령은 [macOS 개발 가이드](docs/macos.md)에 정리했습니다.

## 범용화 방향

WDS의 공통 코어가 입력 정리와 출처 구분을 담당하고, 브라우저 확장과 Mac 앱이 입력창 접근·편집·효과를 담당하는 구조로 옮깁니다. 두 플랫폼에서 판단 규칙과 출처 처리 의미가 달라지지 않도록 공통 로직과 호환성 검증을 공유할 계획입니다.

Inertbox 작업은 WDS의 출처 구분 기능으로 이어갑니다. Mac 앱은 WDS를 사용하는 한 경로이고, 범용화된 코어가 Mac 앱에 의존하지 않도록 합니다. [구조와 사용 목적 처리](docs/product.md)에서 계획을 확인할 수 있습니다.

## 제품 원칙

- 기존 입력창에서 작업하고, 매번 별도 작성 화면이나 목적 선택창을 거치지 않게 합니다.
- 입력 정리와 출처 구분은 각각 독립적으로 사용할 수 있게 합니다.
- 사용자 요청의 의미를 보존하고, 승인한 구간만 편집합니다.
- 출처와 사용 목적을 구분합니다. AI가 작성했다는 사실만으로 사용자의 채택 여부를 판단하지 않습니다.
- 출처를 모르면 추측해 요청의 의미를 바꾸지 않습니다.
- 초안 처리는 기기 안에서 수행합니다. 현재 초안 원문을 로그·디스크·네트워크에 저장하지 않습니다.
- 출처 라벨과 해시는 작성자나 주장의 진실성을 보증하지 않습니다. AI 응답 품질 향상을 검증한 제품이라고 주장하지 않습니다.
