# WDS 제품 방향

제품 이름은 **WDS — What Did you Say?**다.

사용자에게 보이는 제품 소개와 구현 상태는 [README](../../README.md), 상세 방향은 [제품 문서](../../docs/product.md)에 둔다. 이 파일은 그 문서를 찾기 위한 개발용 안내다. 문서의 구현 주장은 실제 코드와 실행 결과로 다시 확인한다.

## 현재 방향

- WDS는 입력 정리와 출처 구분을 제공하는 범용 제품으로 확장한다. Mac 앱은 플랫폼별 연결부 중 하나다.
- 두 기능은 각각 켜고 끈다. 하나의 엔진 스위치에 묶지 않는다.
- Inertbox 작업은 WDS의 출처 구분 기능으로 이어간다.
- 출처와 사용 목적을 구분한다. 다른 세션 토론용 의견, 검토 중인 개선 프롬프트, 사용자가 실제 요청으로 채택한 개선본은 같은 역할이 아니다.
- 매번 목적 선택을 요구하는 UI를 만들지 않는다. 자동 표시와 예외 수정의 구체적인 UX는 아직 설계 단계다.
- 입력 정리는 의미를 보존하는 제한적인 편집 제안이다. WDS 자체가 모델로 프롬프트 전체를 재작성하는 기능과 구분한다.
- 초안은 로컬에서 처리하고 승인한 구간만 편집한다. 전송 버튼이나 Enter를 대신 누르지 않는다.

## 구현과 계획의 구분

현재 `main`은 Mac 군더더기 후보·삭제·효과 경로다. 출처 구분·독립 스위치·교정·터미널 검토 UI는 README에 연결된 작업 브랜치에 있다. 공통 코어·브라우저 확장·자동 출처 표시·목적과 채택 모델은 아직 미구현이다.

과거 Mac 프로토타입의 플랫폼 제약을 제품 전체의 영구 제약으로 해석하지 않는다. 과거 실험의 시장·논문·효과 주장은 재검증 없이 제품 사실이나 사용자 지시로 인용하지 않는다. [Mac 구현 규칙](engineering.md)은 현재 해당 코드에 적용한다.
